# 📱 Wallpapers App

Wallpapers App — bu Android platformasi uchun ishlab chiqilgan zamonaviy va intuitiv fon rasmi ilovasi. Ilova foydalanuvchilarga yuqori sifatli fon rasmlarini ko‘rish, yuklab olish va qurilma fon rasmi sifatida belgilash imkonini beradi.

## ✨ Asosiy funksiyalar

- 🔍 **Kategoriya bo‘yicha saralash** — Tabiat, Kosmos, Minimalistik va boshqa turkumlarda fon rasmlari.
- 🖼️ **Full-screen preview** — Rasmlarni to‘liq ekran ko‘rinishida ko‘rish.
- ❤️ **Saqlanganlar** — Sevimli rasmlarni saqlab qo‘yish va ularga tezda qaytish.
- 📥 **Yuklab olish** — Rasmlarni qurilmaga saqlash imkoniyati.
